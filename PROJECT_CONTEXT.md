# РАДАР М — контекст проекта

Основной продукт — Telegram-канал с ежедневной хронологией подтверждённых и неподтверждённых изменений. Бот — publisher, интерактивный архив источников и admin review; пользовательский анализ по запросу отсутствует.

TypeScript/Node backend с serverless endpoints для Vercel, без frontend/Next.js. Supabase Postgres хранит реестр, статьи, findings, run progress, сигналы, неизменяемые выпуски, очередь, аудит и расходы. Supabase Cron вызывает защищённый worker; расписание активируется отдельно. xAI Responses — первый AIProvider, Zod/JSON Schema; LLM извлекает факторы, индекс определяет код.

Региональный сигнал отделён от федерального, юридический baseline — от daily index. Нет данных — unknown/null, не 0. Перепечатки не являются независимыми подтверждениями. Сравнение стрелки — с предыдущим опубликованным выпуском.

По умолчанию REQUIRE_REVIEW_ALL=true и AUTO_PUBLISH_SAFE_REPORTS=false. Подозрительная/неоднозначная отправка Telegram блокируется без автоматического retry. Архив источников привязан к public_id выпуска, не заменяется следующими запусками.

Реестр: 55 активных источников, 15 регионов; часть источников требует специальных адаптеров. Четыре миграции применены к существующему Supabase. Локальный PostgreSQL dry-run, unit/integration и откатываемые live DB проверки реализованы. Live AI/Telegram не подтверждены: xAI региональный 403, Telegram connect timeout из среды разработки. Cron/webhook/deployment не активированы; публичных тестовых сообщений нет.

Команды запуска и оставшиеся действия: README.md. Фактические результаты: docs/VERIFICATION.md. Секреты только в игнорируемом `.env.local` и серверной конфигурации. Не печатать значения и не коммитить их. Исходные .txt и изображение сохранять.
